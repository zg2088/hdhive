# 验证范围与交付门槛

## 离线验证命令

在干净公开候选目录运行，不需要私有镜像，不连接 Docker daemon：

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -W error -m unittest discover -s tests -v
PYTHONDONTWRITEBYTECODE=1 python3 scripts/verify_public.py
```

仅使用 Python 标准库；没有 pytest 依赖。临时目录遵循 `TMPDIR`，不读取现有业务安装。调用 Git 的测试只在临时仓库初始化；候选目录本身没有初始化 Git、创建远端或发布。

## 本候选的实际验证结果

- Python 标准库 unittest：**22项全部通过，无 skipped**，使用 `-W error` 将警告视为错误；真实伪终端、Compose解析与Git忽略检查均执行。
- `scripts/verify_public.py`：通过。仅列白名单内安装文件；没有应用源码、网页资源、服务端、Dockerfile或私有镜像。
- 执行环境的 Docker CLI：29.9.2；Compose：v5.6.1。未安装 pytest，但本项目不依赖它。
- 未创建、拉取、构建、启动或变更 Docker 镜像/容器；未连接真实业务账户。

## 已覆盖的自动化契约

- **公开文件边界**：严格文件白名单，只允许安装器、文档、示例和独立测试；拒绝核心目录、网页、服务端、Dockerfile、意外测试夹具、运行数据、归档和符号链接。公开目录没有真实配置、许可证状态或镜像。
- **安全向导**：标准库实现，离线输入格式验证、类型和默认值；错误不显示输入值；不回显的字段覆盖身份 ID、Token、Hash、手机号、密码及 OAuth 参数。
- **真实伪终端**：运行完整交互流程并断言所有合成秘密均未出现在终端记录；重定向输入被拒绝，无配置写入。
- **权限及已有安装保护**：0600文件、0700数据目录；宽松 umask 不能放宽结果；拒绝覆盖、已有会话、符号链接、并发向导锁和迟到创建的目标；取消不遗留锁或秘密文件；显式替换需确认停服。
- **真实 Compose 解析**：合成配置写入临时目录，执行 `docker compose config -q` 及 JSON 输出解析，不构建、不拉取、不创建或启动容器。核对本机镜像标签、never拉取策略、受保护的 run 入口、仅相对数据挂载、127.0.0.1端口、禁止特权/提权/全部 capabilities、无自动重启、可选监听 profile、配置输出不含合成秘密。
- **真实入口执行**：从 Compose解析出固定 umask/exec wrapper，在本地子进程创建文件，确认0600，带 `$`、引号等的参数被原样保留且不执行 shell。
- **真实 Git 忽略测试**：临时仓库中执行 `git check-ignore`，检查全部公开文件不会被忽略，而核心代码、真实配置、会话、证书、私有镜像和归档会被忽略。

缺少 Git 或 Docker Compose 时相关测试会 skipped；skipped 不代表通过。文件白名单检查不代替内容秘密扫描、完整 Git 历史审查或核心代码审计。初始化后的实际安装不是干净发布目录，白名单拒绝运行数据是预期行为。

## 尚未验证，不能声称可部署完成

- **本地或正式私有镜像的存在、来源和摘要**：没有凭空生成、导入或替换镜像，也没有借用其他标签冒充交付。
- **镜像接口与内容**：所有者必须在正式交付镜像中确认工作目录、数据目录、网页资源，以及 `python -m hdhive_license.supervisor activate` / `run api` / `run bot` / `run listener` 的契约。Compose与文档按当前接口准备，但离线解析不能执行镜像内部代码。
- **在线许可证**：首次激活、设备绑定、功能范围、续验、过期/撤销后停止、恢复后手动启动、断网行为和升级兼容性。

- **公开发布资格**：仓库地址、公开授权、再分发权与适用许可证由所有者确认；未登录、创建或推送 GitHub。
